# T-0016: Design, render and verify the first Adam-and-Axel family PDF

**Status**: DONE | **Size**: M
**Phase**: COMPLETE

## Context

The owner approved a polished private family PDF as the presentation form for
the shared sibling-root depth-4 edition defined by `PCR-2026-08-22-001` and
`PCD-2026-08-22-001`. It must render the verified T-0015 cohort faithfully,
including evidence status and documented unknowns, rather than behaving as an
unqualified tree export.

## Acceptance Criteria

- [x] Create a visually coherent Swedish PDF with a shared Adam-and-Axel title
  page, readable depth-4 pedigree, concise person portraits, source notes,
  uncertainty legend and research-front statement.
- [x] Use privacy-minimal treatment for living people and do not expose
  unrelated private data.
- [x] Distinguish archival facts, family statements, leads, conflicts and
  documented unknowns typographically and verbally.
- [x] Include stable Riksarkivet references and a generation date/version.
- [x] Include a readable Sweden map of source-backed residences, using the
  family branches consistently, showing evidenced movement only, marking
  approximate locations and avoiding label collisions or false precision.
- [x] Include a selective sourced timeline that aligns the family branches and
  generations; distinguish exact dates, years and approximate periods.
- [x] Include at least one legible handwritten-source close reading that does
  real evidentiary work: original crop, diplomatic transcription, modern reading
  help, exact reference and a bounded statement of what the record proves and
  does not prove.
- [x] Include a dedicated reader-friendly `Källorna bakom berättelsen` section,
  not merely short references: explain what each source family is, when and why
  it was produced, what it can usually establish, and its characteristic limits;
  retain exact archive/volume/image references for verification.
- [x] Give each main portrait a compact `Syskon och uppväxtfamilj` element when
  source-backed data exists; keep lists legible and expand only selected sibling
  stories that materially illuminate the family.
- [x] Save the final artifact under `output/pdf/` with a stable descriptive
  filename.
- [x] Render every page to PNG, inspect all pages, correct every clipping,
  overlap, glyph, contrast, spacing and pagination defect, and verify the final
  PDF structure and extractable text.

## Approach

Build from T-0015's verified edition manifest, use a restrained archival visual
language and generate the PDF programmatically for reproducibility. Treat the
tree as a visual overview and the portraits/source appendix as the evidentiary
explanation.
