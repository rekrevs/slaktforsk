**Status**: DONE | **Size**: M
**Phase**: -

## Context

Ägaren vill avskaffa separat handover och återuppta avbrutet arbete via
vanlig uppgiftsstatus. Godkännande 2026-09-05: ”läser projektet
wotan/README.md? förtydliga. och lös resten så att det fungerar bra.”
Beslutet bevaras i PCD-2026-09-05-003 i [Project Control](../../PROJECT-CONTROL.md).

## Scope

Projektets styrfiler, Wotan-konvention och konkreta kvarstående arbeten från
denna session. Inga globala skilländringar, ny släktforskning, nya PDF:er,
publicering, commit eller push. Befintlig stor smutsig arbetsyta bevaras.
Ingen generell migration eller ny arkivering av HANDOVER-innehåll.

## Acceptance Criteria

- [x] AGENTS kräver att wotan/README läses före uppgiftsval och återupptagning.
- [x] Uppgifter har ändligt omfång, verifierbart resultat och eget sparat arbetsläge.
- [x] Sessionsavbrott, hinder, återläsning och upprepningsrisk hanteras uttryckligen.
- [x] Tom kö hanteras olika vid kökörning respektive kontinuerligt north-star-mål.
- [x] HANDOVER.md och aktiva läsinstruktioner till den är borttagna; historik består.
- [x] Aktuella kvarstående arbeten finns som avgränsade uppgifter, inte startprosa.
- [x] Uppgiftsval, referenser, backlog och relevanta regressioner är verifierade.

## Approach

1. Granska kanoniska styrfiler, beslutslogg och backlog utan att rekonstruera
   all gammal handover-prosa.
2. Förtydliga läsordning, ansvar, avgränsning och återupptagningskontrakt.
3. Bevara avslutsrevision och kända kodluckor i separata uppgifter.
4. Ta bort redundant handover, kontrollera startvägen och kör kontroller.
