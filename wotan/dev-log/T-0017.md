# T-0017: Preserve the genealogy workspace in a private GitHub repository

**Status**: ONGOING | **Size**: M
**Phase**: VERIFYING

## Context

The project contains durable source-led genealogy records and 1.1 GB of retained
source media but has no version control or off-machine repository. The owner
approved a private GitHub repository with Git LFS for the source images. Working
state, cookies, caches, and reproducible intermediate output must not be pushed.

## Acceptance Criteria

- [ ] Initialize Git with explicit privacy and generated-file exclusions.
- [ ] Track durable source media and retained final artifacts through Git LFS.
- [ ] Generate a machine-readable media manifest that records every retained
      media file's citation identity, size, and SHA-256 without inventing
      missing source metadata.
- [ ] Verify genealogy integrity, media coverage, secret hygiene, Git/LFS state,
      and a clean reproducible initial commit.
- [ ] Create `rekrevs/slaktforsk` as a private GitHub repository and push the
      verified branch.
- [ ] Restore T-0012 as the single active research task after preservation.

## Approach

Keep human-readable project memory, provenance records, Wotan state, scripts,
and source media together. Use ordinary Git for text and small structured data,
Git LFS for binary source artifacts, and an ignored local `tmp/` boundary. Add
a generated manifest and a verifier so exact artifact integrity can be checked
even when some older batch images have only range-level citation metadata.
