# T-0640: Genealogy2 — verifierbar importbas och förlustfri SQLite-import

**Status**: DONE | **Size**: L
**Phase**: -

## Context

Ägaren godkände övergångsförslaget i IDEA-0001 med ”vi kör så, kör igång!”
och uppgav att ordinarie forskning i genealogy inte drivs vidare under tiden.
Mandat: PCD-2026-09-16-001. Detta är teknisk import, inte ny arkivforskning.

## Scope

Fast import av alla beständiga filer under genealogy samt befintliga
styr-/beslutsfiler och Wotan-historik som provenans. Media verifieras och
refereras på befintlig plats. Nya utvecklingsloggar ingår inte rekursivt
i importbasen. Genealogy, dess inventering och dashboard ska inte ändras.
Typad saklig konvertering och domänskrivning hör till T-0641 och senare.

## Acceptance Criteria

- [x] En innehållsadresserad, kontrollerbar importbas bevarar exakta textbyte
      samt filinventering och mediahashar; avvikelse från basen upptäcks.
- [x] SQLite innehåller alla ursprungsdokument samt mekaniskt utvunna personer,
      källakter, citationer, A-rader, profilfrågor/källvägar och dokumentavsnitt.
      Historiska citat förväxlas inte med aktuella rader.
- [x] Ursprung kan följas till filversion och exakt textspann. Ingen semantisk
      uppgradering eller automatisk personförening sker.
- [x] CLI kan söka, visa, rapportera täckning, exportera och verifiera importen.
- [x] Samma import kan köras igen utan dubbletter; ändrad bas eller okänd
      schemaversion avvisas; misslyckad import lämnar inga halvskrivna poster.
- [x] Backup/export kan återställas i en ny databas och jämföras med originalet.
- [x] Den gamla kanoniska forskningen och dashboarden är oförändrade.

## Verification Plan

Enhetstester för Markdown-gränser och id:n; integrationstester på ett litet
separat testarkiv med avbrott, ändrad indata, felaktiga referenser och omimport.
Full import av det riktiga arkivet med antal/hashavstämning och återställningsprov.
Relevanta befintliga validatorer och regressioner körs utan dashboarduppdatering.

## Approach

Node med inbyggd SQLite, utan externa runtimeberoenden. Bevarad importbas
och granskningsbar export hålls skilda från databasen som senare ska äga
nya ändringar. Importstatus är skild från befintlig evidensstatus.
