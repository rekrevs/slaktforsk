# T-0031: Redesign the depth-5 family edition for efficient paper use and clearer pedigree trees

**Status**: DONE | **Size**: M
**Phase**: -

## Context

The owner found the verified version 2 wasteful of paper: decorative cards,
colour fields and excess whitespace displaced content, while its ancestry
overviews were not clear enough as family trees. `PCR-2026-09-04-004` and
`PCD-2026-09-04-004` therefore redirect the edition work before depth-6
research resumes.

Versions 1 and 2 are immutable reference editions. Version 3 reuses the
verified version-2 content but changes the page architecture and tree drawing.

## Acceptance Criteria

- [x] Version 1 and version 2 remain byte-for-byte unchanged.
- [x] A separate, stably named version-3 PDF removes decorative cards,
  coloured panel backgrounds and unjustified whitespace while remaining
  comfortable to read rather than extremely compressed.
- [x] The 31-page version-2 content is reduced to a materially smaller page
  count without dropping any of its 32 depth-5 people, evidence distinctions,
  feature stories, map/place material, timeline, source close readings,
  research fronts or exact references.
- [x] Two connected pedigree diagrams, one for each parent side, show five
  generations with unambiguous parent-child lines and readable names.
- [x] A version-3 manifest, deterministic builder and structural verifier make
  the edition reproducible and confirm the promised content and invariants.
- [x] Every rendered page is visually inspected at readable scale; no text,
  line, image or footer clips or overlaps.

## Verification Plan

Record SHA-256 for versions 1 and 2 before and after. Build version 3, run its
structural verifier, inspect PDF metadata and extracted text, render every page
to PNG, build contact sheets and inspect individual pages where density is
highest. Then run the repository genealogy validators and tests.

## Approach

Use a restrained black-and-white editorial system with typographic hierarchy,
thin functional rules and compact continuous text. Use portrait pages for
narrative material and A4 landscape only where it improves the two connected
pedigree diagrams. Consolidate related content onto fewer pages, but keep body
text and tree labels readable.
