# T-0005: Backfill dossiers for all already-discovered relatives

**Status**: DONE | **Size**: M

## Context

The research program now requires opportunistic capture of every named person
in target entries, households and relationship-bearing annotations. Earlier
work captured many such people, but several named parents, siblings and other
relations still occur only inside claims or citations and lack their own
person dossier.

## Acceptance Criteria

- [x] Inventory existing sources, citations and person claims for named people without P-ids.
- [x] Create or reconcile one dossier per distinct named person, avoiding duplicate identities.
- [x] Preserve private or probably living people with only the minimum necessary data.
- [x] Link every backfilled fact to its exact source/citation and evidence status.
- [x] Update the tree, frontier and research log with the resulting side branches and unresolved identities.
- [x] Verify all Markdown links and the consistency of P-id references.

## Approach

Audit the existing evidence from oldest citation to newest. Extract people in
the target entry, target household or explicit relational annotation; do not
profile unrelated entries that merely share a scanned page. Create provisional
records when identity is incomplete and record conflicts rather than merging
on name alone.
