# Kartunderlag för familjeutgåvan

`sweden-outline-natural-earth-5.1.1.geojson` är en härledd Sverigegeometri
från **Natural Earth, Admin 0 – Countries, 1:10m, version 5.1.1**.

- Källa: <https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/>
- Hämtad: 2026-08-22
- Ursprunglig fil: `ne_10m_admin_0_countries.zip`
- Urval: `ADM0_A3 = 'SWE'`
- Export: GeoJSON med GDAL/OGR, förenkling 0,002 grader

Utgåvans ortspunkter kommer från OpenStreetMap Nominatim, avlästa
2026-08-22. Exakt sökfråga, vald träff, källbelagd person/händelse, period och
`approximate`-flagga finns för varje punkt i
`../adam-axel-depth4-v1.json`. Punkterna är moderna orienteringspunkter, inte
påståenden om exakta historiska fastighetskoordinater.
