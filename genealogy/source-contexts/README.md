# Gemensamma källkontexter

Återanvänd kontrollerad ort-/tids-/jurisdiktions- och arkivrouting när flera
personer delar samma källvägar. Använd [mallen](../templates/source-context.md)
och [källstrategin](../source-strategy.md). Källkontexten är metadata och
kan inte i sig belägga personförekomst, identitet eller ett personnoll.

Skapa bara en post när den sparar faktisk upprepning. Kontrollerat datum,
exakt täckning, härledning, tillåten åtkomst och berörda personprofiler ska
framgå. Utförande och återupptagning finns endast i Wotan.
