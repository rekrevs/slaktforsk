## Teckenförklaring

| Kod | Betydelse |
|---|---|
| `✓` | använd med personrelevant positiv eller identifierande information |
| `N` | avgränsad negativ kontroll eller fysisk lucka är dokumenterad |
| `Ö` | källan har återöppnats i inloggad webbvy men målposten är ännu inte läst |
| `S` | konkret åtkomstspärr kvarstår; inte ett negativt källresultat |
| `1` | högprioriterad, relevant och ännu oprövad källfamilj |
| `2` | villkorligt relevant efter utfallet i högre prioriterade källor |
| `I` | endast ägaruppgift/integritetsminimerad ingång för sannolikt levande person |
| `—` | ingen nuvarande saklig trigger; omprövas om nya uppgifter tillkommer |

Kolumnerna betyder: `F` födelse/dop, `H` husförhör/församlingsbok, `M`
flyttning, `V` vigsel/lysning, `D` död/begravning, `R` folkräkning,
församlingsutdrag och SCB, `B` bouppteckning, `T` mantal/skatt, `J`
domstol/sockenstämma/fattigvård och `O` yrkesutlösta källor såsom militära
rullor, jord/lagfart eller sjömanshus.
