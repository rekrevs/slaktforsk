# T-0805 bounded semantic amendment

The settled singular material schema is retained. New searches over multiple material units are split into separate versioned search receipts, each with its own actual material, query, coverage, source revision and subject links. Structural validation cannot certify substantive completeness or detect an undisclosed umbrella scope; source review remains mandatory.

A documentary correction is not a newly performed search. Never fabricate performed_at or upgrade unknown legacy provenance. The native write path requires complete metadata even for a new negative revision. If inherited provenance is insufficient, preserve the historical search and record the correction in a supported assessment/conflict referring exactly to the original receipt; an expanded correction workflow requires separate bounded design. Unmarked low-level apply is historical compatibility, not an authorized opt-out.

Primary Astra agreed these dispositions and approved exact normative pins in primary-normative-review-v2.json. Original specification and both earlier reviews are retained.
